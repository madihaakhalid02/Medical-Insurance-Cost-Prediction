# Medical-Insurance-Cost-Prediction
# 💡 End-to-End Medical Insurance Cost Prediction

A complete Machine Learning web application and regression model built to predict individual medical insurance costs based on personal health attributes and demographics. Developed as part of a professional machine learning internship portfolio.

## 🚀 Project Overview
Medical cost forecasting helps insurance companies estimate charges accurately based on risk factors like age, BMI, smoking status, and region. This project covers the complete end-to-end pipeline: from Data Collection and Exploratory Data Analysis (EDA) to Model Training and Web Deployment.

## 🛠️ Tech Stack & Libraries
* **Language:** Python
* **Data Processing & Analysis:** Pandas, NumPy
* **Machine Learning:** Scikit-learn (Linear Regression)
* **Visualization:** Matplotlib, Seaborn
* **Deployment:** Streamlit, LocalTunnel

## 📊 Model Evaluation Metrics
The model was evaluated using standard regression performance metrics:
* **Mean Absolute Error (MAE):** Measures average absolute prediction error.
* **Mean Squared Error (MSE) & Root Mean Squared Error (RMSE):** Penalizes larger deviations effectively.
* **R² Score:** Evaluates overall model goodness-of-fit and accuracy.
